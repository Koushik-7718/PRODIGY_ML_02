Customer Segmentation Using K-Means Clustering

Overview

This project implements the K-Means Clustering algorithm to segment retail store customers into different groups based on their purchasing behavior and demographic information. The goal is to identify meaningful customer segments that can help businesses make data-driven marketing decisions.

Dataset Features

- Customer ID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Project Workflow

1. Data Loading and Exploration
2. Data Preprocessing
3. Feature Selection
4. Determining Optimal Clusters using the Elbow Method
5. Applying K-Means Clustering
6. Visualizing Customer Segments
7. Interpreting Cluster Characteristics

Key Concepts Learned

- Unsupervised Machine Learning
- Customer Segmentation
- K-Means Clustering Algorithm
- Elbow Method
- Cluster Visualization
- Business Insights from Data

Results

The model successfully grouped customers into distinct clusters based on their income and spending patterns. These segments can be used for targeted marketing, customer retention strategies, and personalized recommendations.
